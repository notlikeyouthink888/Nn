# 🏗️ المنصة الإنشائية — تحليل وتصميم الهندسة المدنية

موقع ويب متكامل للتحليل والتصميم الإنشائي، مبني بلغة **Python بالمكتبة القياسية فقط**
(بدون أي اعتماديات خارجية) + واجهة عربية (RTL) برسومات SVG.
يعمل على المنفذ **5819**.

## المحاور

| القسم | الوصف |
|---|---|
| 🪄 معالج المشروع | تكتب مساحة القطعة وعدد الطوابق ونوع التربة → شبكة أعمدة وأحمال ونوع الأساس وتصميمه وكميات الحفر والردم، مع **مجسم ثلاثي الأبعاد** تفاعلي |
| 📐 المساحة | مساحة ومحيط من الإحداثيات · اتجاهات وزوايا · دفتر مناسيب (HI) · قطع وردم بطريقة الشبكة |
| ⛏️ الحفر والردم | المناسيب من البنج مارك · طبقات الجلمود والسبيس وعددها · معاملات الانتفاش والدك · الكميات |
| 🪨 التربة والركائز | قدرة التحمّل (Terzaghi/Vesic) · قدرة الركيزة (α للطين، Meyerhof-SPT للرمل) · كفاءة المجموعة · أنواع الركائز ومتى تُستعمل |
| ⚖️ الأحمال | جداول الأحمال الحية وكثافات المواد (الكود العراقي) + حاسبة تركيب الطابق |
| 🌊 التحليل الزلزالي | طريقة القوة الجانبية المكافئة: V = Cs·W وتوزيع القوى على الطوابق |
| 💨 أحمال الرياح | qz = 0.613·Kz·Kzt·Kd·V² وتوزيع الضغط مع الارتفاع |
| 📏 الجسور | تحليل مصفوفي للجسور المستمرة + تحميل نمطي + BMD/SFD/هطول + تسليح كامل |
| 🏛️ الأعمدة | منحني تفاعل P–M بالتوافق الانفعالي + فحص النحافة وتكبير العزوم |
| 🧱 الأسس | الأبعاد + قص الثقب + القص الأحادي + الانحناء + الارتكاز |
| ⬜ البلاطات | أحادية الاتجاه (معاملات ACI 6.5.2) وثنائية الاتجاه (DDM) |
| 🩻 X-Ray الإنشائي | تحليل الإطار الكامل وتصميم كل عنصر مع خريطة نسب الاستغلال |
| 📋 جدول الكميات | الخرسانة والحديد والقوالب والكلفة التقديرية بالدينار العراقي |

## الأكواد المعتمدة
- **ACI 318-19** (SI) للتصميم الخرساني.
- **ASCE 7-16** لتراكيب الأحمال وطريقة ELF الزلزالية.
- **الكود العراقي للأحمال والقوى** لجداول الأحمال الحية وكثافات المواد.

> قيم Ss و S1 لكل محافظة استرشادية — تُدقق من خرائط الكود العراقي المعتمدة.

## التشغيل محلياً
```bash
PORT=5819 python3 app.py     # ثم افتح http://localhost:5819
```

## التنصيب على سيرفر
```bash
bash install.sh              # ينصّب في /opt/civil5819 وينشئ خدمة systemd على المنفذ 5819
```
`install.sh` مولَّد آلياً من المصادر عبر `./build_installer.sh` (ذاتي الاحتواء: يحمل الملفات مضغوطة داخله).

## الملفات
- `project.py` — المعالج: من المساحة إلى حزمة الأساسات + حفظ المشاريع.
- `found.py` — التربة والأسس والركائز والحصيرة ومستشار نوع الأساس.
- `earth.py` — الحفريات والردم والمناسيب وطبقات الجلمود والسبيس.
- `survey.py` — أعمال المساحة.
- `dxf.py` — تصدير مخطط الأسس بصيغة DXF (يفتح بالأوتوكاد).
- `static/viewer3d.js` + `static/vendor/` — العارض ثلاثي الأبعاد (Three.js مستضاف محلياً، بدون CDN).
- `engine.py` — محرك الحسابات: محلل الإطارات المستوية بطريقة الصلابة المباشرة + دوال تصميم ACI + أحمال الكود العراقي.
- `app.py` — خادم HTTP (مكتبة قياسية) يقدّم الواجهة و REST API تحت `/api/*`.
- `static/` — الواجهة (HTML/CSS/JS بدون أي مكتبة خارجية).
- `civil5819.service` — وحدة systemd.

## التحقق من صحة المحلل
تمت مطابقة نتائج المحلل مع الحلول المرجعية:
جسر بسيط الإسناد (wL²/8، 5wL⁴/384EI)، مثبت الطرفين (∓wL²/12، +wL²/24)، كابولي (PL، PL³/3EI)،
مسنود-مثبت (wL²/8، R=5wL/8)، مستمر بفضاءين (wL²/8، R=1.25wL)، وإطار بورتال (توازن القص).

> أداة مساعدة للمهندس ولا تُغني عن تدقيق مهندس مُجاز ومصادقة الجهات الرسمية.
